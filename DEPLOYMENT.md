# AI Marketplace deployment guide

## Recommended SaaS stack for free-tier MVP

- Frontend: Vercel (free tier)
- API: Render or Railway (free tier / low-cost)
- Database: Supabase Postgres (free tier)
- Cache: Upstash Redis (free tier) or managed Redis
- Storage: Supabase Storage
- Payments: Stripe test/live

## Production architecture

- Web app: Vercel next app
- API app: Render / Fly.io / Railway
- Auth: JWT or Supabase Auth
- Database: Supabase Postgres
- Cache: Upstash Redis
- Billing: Stripe webhooks

## Environment variables

### Frontend (Vercel)

```bash
NEXT_PUBLIC_APP_URL=https://your-app.vercel.app
NEXT_PUBLIC_API_URL=https://your-api-url.onrender.com
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### Backend (Render/Fly/Railway)

```bash
APP_ENV=production
API_V1_STR=/api/v1
PROJECT_NAME=AI Marketplace API
DATABASE_URL=postgresql+asyncpg://postgres:<password>@db.<project>.supabase.co:5432/postgres
REDIS_URL=redis://default:<password>@<host>:6379
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
SECRET_KEY=super-secure-random-secret
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440
```

## Supabase database setup

Create a new Supabase project and run these tables:

```sql
create table users (
  id bigint generated by default as identity primary key,
  email text unique not null,
  name text,
  avatar_url text,
  role text default 'buyer',
  hashed_password text default '',
  is_active boolean default true,
  created_at timestamptz default now()
);

create table products (
  id bigint generated by default as identity primary key,
  slug text unique not null,
  title text not null,
  category text not null,
  short_description text,
  description text,
  status text default 'draft',
  price double precision default 0,
  is_free boolean default false,
  seller_id bigint,
  created_at timestamptz default now()
);

create table subscriptions (
  id bigint generated by default as identity primary key,
  user_id bigint,
  product_id bigint,
  plan_name text,
  status text default 'active',
  stripe_subscription_id text,
  current_period_end timestamptz,
  created_at timestamptz default now()
);

create table licenses (
  id bigint generated by default as identity primary key,
  user_id bigint,
  product_id bigint,
  license_key text unique not null,
  status text default 'active',
  expires_at timestamptz,
  created_at timestamptz default now()
);

create table reviews (
  id bigint generated by default as identity primary key,
  product_id bigint,
  user_id bigint,
  rating integer check (rating between 1 and 5),
  comment text,
  created_at timestamptz default now()
);
```

## Deploy steps

1. Push repository to GitHub.
2. Create Vercel project for the frontend from the `apps/web` app.
3. Create Supabase project and copy DB URL and anon key.
4. Create Redis service via Upstash or managed Redis.
5. Create Stripe account and set up product prices.
6. Create Render/Fly/Railway service for the FastAPI app.
7. Add environment variables.
8. Configure Stripe webhook to call `https://<your-api>/api/v1/webhooks/stripe`.
9. Test checkout flow and license issuance.
10. Launch and monitor.

## Recommended final production stack

- Frontend: Vercel
- Backend: Render / Fly.io / Railway
- Database: Supabase Postgres
- Cache: Upstash Redis
- Auth: JWT + Supabase Auth
- Payment: Stripe
- Storage: Supabase Storage

This gives you a free-to-start, scalable architecture that is production-friendly and easy to evolve.
